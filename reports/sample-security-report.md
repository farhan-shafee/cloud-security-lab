# Synthetic assessment report

The report is generated from committed fixtures:

- [Before assessment](generated/before.md)
- [After assessment](generated/after.md)
- [Detection and triage](generated/detections.md)
- [Remediation verification](generated/verification.md)
- [Machine-readable summary](generated/summary.json)

Reproduce with `python -m cloud_security_lab demo --output-dir reports/generated`.

These reports describe synthetic configuration remediation verification. They do not establish compliance, a connected AWS service, or deployed cloud changes. Executed local/CI checks are recorded separately in [VALIDATION.md](../docs/VALIDATION.md).
