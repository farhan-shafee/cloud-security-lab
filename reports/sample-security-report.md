# Cloud Security Portfolio Lab - Sample Assessment Report

## Executive Summary
This portfolio lab assessment identified one high-severity and two medium-severity issues related to identity hygiene and suspicious activity monitoring.

## Scope
- IAM policy posture
- Authentication event review
- Threat detection finding triage

## Key Results
- Excessive privilege found in one sample IAM policy.
- Authentication event without MFA observed.
- One anomaly finding requiring analyst investigation.

## Recommended Next Steps
1. Enforce MFA and remove non-compliant users from privileged groups.
2. Eliminate wildcard IAM permissions.
3. Formalize SOC triage playbook for cloud identity alerts.
