# Remediation Checklist

- [ ] Enforce MFA for all interactive users.
- [ ] Remove wildcard (`*`) actions from IAM policies unless explicitly justified.
- [ ] Scope IAM resources to specific ARNs/resource IDs.
- [ ] Enable organization/account-level audit logging.
- [ ] Route high-severity findings to incident response workflow.
- [ ] Set log retention and integrity controls.
- [ ] Document break-glass access process.
- [ ] Validate remediation by re-running policy/event checks.
