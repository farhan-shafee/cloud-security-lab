# Security Policy

## Scope
This repository is a portfolio lab and does not operate a production service.

## Reporting
If you identify a security issue in the repository contents (e.g., accidental secrets), please open a private report through repository security advisories or contact the maintainer.

## Safe Handling
- Do not commit real credentials.
- Use sample/sanitized cloud event data only.
- Rotate and revoke any accidentally exposed keys immediately.
